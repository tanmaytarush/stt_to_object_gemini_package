# Example spoken turns for voice_logging (Items section only).
#
#   cd scripts
#   python -m voice_logging --contractor-id 1 --client-id 12 --text
#
# Paste ONE line at a time. A blank line clears the list.
# Lines starting with # are notes — do not paste those.
#
# Voice fills item / qty / uom. Dealer, client, order type, amount and dates
# come from the screen. If they are said in the same breath, ignore them.
#
# Expected after the first Hinglish one-shot (with --client-id 12):
#   orderItems: 10 bag cement, 5 kg Fevicol SH, 2 tin Dr. Fixit

# ---------------------------------------------------------------------------
# ENGLISH
# ---------------------------------------------------------------------------

# One shot — three complete rows
Ten bags cement, five kg Fevicol SH, two tins Dr. Fixit.

# One row per turn — they append
twenty bori TMT
three packets M-Seal
one roll Roff Rainbow Tile Mate

# Correction — resend the whole list, not just the fixed row
no, eight bags cement and five kg Fevicol SH

# Same breath as a dealer / price — still only the items
Need 15 bags cement and 2 litre Fevicol Marine from Sharma Traders, total twelve thousand.

# ---------------------------------------------------------------------------
# HINGLISH  (Latin script — what SMART STT often returns)
# ---------------------------------------------------------------------------

# One shot
das bag cement, paanch kilo Fevicol SH, do tin Dr. Fixit

# Append
bees bori sariya
teen packet M-Seal
ek peti Fevikwik
chaar nag plywood

# Correction
nahi, aath bag cement aur paanch kilo Fevicol SH

# Items plus chatter that must NOT become rows
das bag cement Sharma Traders se le aana, total bara hazaar
paanch kilo Fevicol SH client Ramesh ke site pe

# Incomplete — drop the row, keep a note
thoda cement bhi laao
paanch cement
dedh bag cement

# No items at all
Sharma Traders ko bhej dena
client Ramesh Kumar ka order hai
total bara hazaar rupaye
kal subah chahiye
haan theek hai

# ---------------------------------------------------------------------------
# HINDI  (Devanagari — also common from live STT)
# ---------------------------------------------------------------------------

दस बैग सीमेंट, पांच किलो फेविकोल एसएच, दो टिन डॉ फिक्सीट।
बीस बोरी सरिया
तीन पैकेट एम सील
नहीं, आठ बैग सीमेंट और पांच किलो फेविकोल।
थोड़ा पुट्टी भी लाओ
शर्मा ट्रेडर्स को भेज देना, बारह हज़ार का बिल है।

# ---------------------------------------------------------------------------
# GUJARATI
# ---------------------------------------------------------------------------

દસ બેગ સિમેન્ટ, પાંચ કિલો ફેવિકોલ એસએચ
બે ટીન ડૉ ફિક્સિટ
ના, આઠ બેગ સિમેન્ટ

das bag cement ane panch kilo Fevicol SH
be tin Dr. Fixit, Gupta Hardware thi
nathi, aath bag cement

# ---------------------------------------------------------------------------
# MARATHI
# ---------------------------------------------------------------------------

दहा बॅग सिमेंट, पाच किलो फेविकोल
दोन टीन डॉ फिक्सीट
नाही, आठ बॅग सिमेंट

daha bag cement ani paach kilo Fevicol SH
don tin Dr. Fixit
nahi, aath bag cement

# ---------------------------------------------------------------------------
# KANNADA  (native script + Latin, as STT often transliterates)
# ---------------------------------------------------------------------------

ಹತ್ತು ಬ್ಯಾಗ್ ಸಿಮೆಂಟ್, ಐದು ಕಿಲೋ ಫೆವಿಕಾಲ್, ಎರಡು ಟಿನ್ ಡಾ ಫಿಕ್ಸಿಟ್
ಇಲ್ಲ, ಎಂಟು ಬ್ಯಾಗ್ ಸಿಮೆಂಟ್

# Latin: hattu=10 aidu=5 eradu=2 mooru=3 naalku=4 aaru=6 elu=7 entu=8 ombattu=9
hattu bag cement, aidu kilo Fevicol SH
eradu tin Dr. Fixit
mooru packet M-Seal
illa, entu bag cement
savira aidu rupayi total — idanna bidu

# ---------------------------------------------------------------------------
# MIXED / MESSY  (one breath: items + dealer + amount)
# ---------------------------------------------------------------------------
# Must yield only the material rows. Names, shops and money stay on the screen.

das bag cement aur paanch kilo Fevicol, dealer Sharma Traders, phone nau aath saat
Hosa samagri hattu bag cement, graahaka Ramesh, savira aidu
maal laao: 10 bag cement, 5 kg Fevicol SH, 2 tin Dr Fixit, kal subah chahiye
